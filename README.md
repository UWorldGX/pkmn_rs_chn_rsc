## 关于文本翻译
本版宝可梦红蓝宝石全汉化为v1版。

我们使用AI大模型进行文本粗翻。大部分文本都经过润色和格式检查以适应游戏显示。

官方译名整体取《宝可梦 晶灿钻石／明亮珍珠》及以后发布的官中名称。由于红蓝宝石年代久远，效果、功能发生变化的道具、招式等做了调整以适应原版内容。

总体游戏文本基于美版英语原文进行翻译，部分表述可能与日版原文存在出入；对战提示信息来自《究极之日／究极之月》的官中翻译。

游戏内的简单短语（涉及到电视节目、对战塔NPC台词等）因涉及原版特有的排列组合表述而未作汉化。

NPC名称等来自神百翻译，部分名称选入时有改动。

红蓝宝石是最后一代图鉴介绍分页显示的宝可梦游戏，汉化图鉴信息如同原版游戏一样分页显示。官方图鉴介绍基底来自神百翻译日版，部分文本会移至介绍2，原文如此；断句方面可能存在令人不适的显示问题，烦请见谅。图鉴中美版计量宝可梦重量的“磅”替换为“千克”，并进行了数据换算。

## 补丁的使用说明
我们为了兼顾不同玩家的游玩体验需求，制作了一系列补丁。

请先打"J"版和"E"版两个后缀名为.bps的基础补丁，再按照需要打后缀名为.ips的语言、功能补丁。

### 关于"J"版与"E"版
"J"是美术风格为日版的版本，本质上仍然为美版v1.2，并非真正的日版。部分文本与图片汉化为"精灵宝可梦"，美术风格上更接近《精灵宝可梦 究极之日／究极之月》及之前的宝可梦游戏。

"E"版是美术风格为美版的版本，文本与图片统一汉化为"宝可梦"，美术风格更接近《宝可梦 剑／盾》至今的官方汉化宝可梦游戏。

两者只有标题美术和部分游戏内文本之分，游戏内容和存档数据完全相同，可以互通。

J版与E版补丁是本汉化的基础补丁，包含汉化字库、汉化图片，和基础汉化文本。注意打上基础补丁后宝可梦默认名称和训练家默认名称仍为英语。

### 关于特殊补丁

日文名称补丁：将宝可梦默认名称改为日文。

(注：若你在意的话，在不改昵称的情况下，该版本所有默认名称的宝可梦均是为不合法，仅适合作为娱乐向补丁)

中文名称补丁：将主角默认名称、宝可梦默认名称汉化为中文。其中一组主角备选名更改为小悠/小遥。

(注：如果你在意的话，所有主角名称为中文或自己名称为中文的宝可梦都不合法，请注意)

特供版补丁：图一乐补丁。将宝可梦名称、道具名称相关的文本和标题图片汉化为当年D商译名。

(注：不包括"结果我第一，又强又厉害"等D商其他文本。请在J版的基础上打该补丁)

### 关于功能补丁
部分Game Freak相关内容汉化补丁：部分文本和可汉化的图片将Game Freak汉化为游戏狂想家等宝可梦版权方在华注册名称。

盲文汉化补丁：汉化组诚意之作，原版各类遗迹盲文谜题将以现行拼音盲文进行汉化。(注：不影响正常游戏流程)

视野修正补丁：修正游戏内视野过大而导致行动轨迹错误的部分训练家，还修复了原版的一部分地图图块错误。(注：不包含任何汉化内容)


## 与其他作品联动/连接交换
在宝可梦和初训家名称均为英语的前提下，与美版GBA宝可梦原版游戏连接交换应无问题；与日版GBA宝可梦原版游戏连接交换类似于原版美版、日版间联动；

经过测试，可以与如下GBA宝可梦汉化游戏正常连接交换：
* 精灵宝可梦 绿宝石（口袋吧 2011版/口袋吧&口袋群星SP 2012典藏版）
* 精灵宝可梦 火红／叶绿（口袋吧&口袋群星SP 2012版）
* 精灵宝可梦 绿宝石（小电 2023版）
* 精灵宝可梦 叶绿／绿宝石（洛水惊鸿 2024版）

汉化版支持与第四世代游戏《精灵宝可梦 钻石／珍珠／白金／心金／魂银》进行联动，联动可行性如下：
* J版可与四代日版/日版汉化识别并正常联动。
* E版可与四代美版正常联动。

与NGC游戏《精灵宝可梦 圆形竞技场》、《精灵宝可梦 XD》等的联动没有经过测试，在使用美版NGC端游戏、宝可梦和初训家名均为英语的前提下联动（诸如宝可梦存取、领取美版特典基拉祈等）应无问题。

> 注：若你在意的话，任何默认宝可梦名称、默认主角名称为非英文的版本虽然能与四代联动，但这并不合法。

> 注：将本汉化版宝可梦传送至Pokémon HOME的唯一官方渠道，《宝可梦虚拟银行》和《宝可梦虚拟传送》即将于2027年2月27日关闭。如有需要请尽快完成转移。
